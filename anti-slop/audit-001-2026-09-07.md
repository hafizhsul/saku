# Audit Redesign UI — 2026-09-07 (audit-001)

Design Read: finance mobile app for Indonesian users, emerald "Safe Stewardship" language, dial ENERGY 2 / RHYTHM 2 / MOTION 1.
Direction: `DESIGN.md` + `src/theme/index.tsx` ada. Bukan draft without direction (R-37 PASS).
Scope: Beranda, Analisis, Detail Saku, Profil/Settings + screenshot redesign (`analisis-redesign.png`, `add-final.png`, `detail-redesign.png`, `profil-redesign-full.png`).

## Findings

1. [HIGH] Hardcoded hero/chart colors bypass tema (R-34, R-29) — `app/(tabs)/analisis.tsx:24-39` HERO/SURFACE_TINT/CHART_* konstan hex, dark mode hanya di-patch parsial (`surfaceTint`, `titleColor`). Alasan satu baris tidak ada.
2. [HIGH] Tombol mati `Hubungkan Bank/E-wallet` (R-26) — `app/(tabs)/settings.tsx:30,102` `noop()` sebagai onPress. Kontrol non-fungsional wajib dibuang atau dilabel "Segera hadir" + TODO.
3. [HIGH] Foto avatar asumsi (R-23) — `app/(tabs)/settings.tsx:66` fallback `avatar-budi.jpg` untuk semua pengguna baru. Wajib placeholder inisial, bukan foto orang lain.
4. [HIGH] Risiko bottom-nav menutup konten (R-03) — tab bar floating + FAB tengah (`app/(tabs)/_layout.tsx`), `ScreenShell` reserve 112px. Di screenshot Profil, baris "Pusat Bantuan" terpotong nav. Verifikasi `paddingBottom` + safe-area di layar panjang.
5. [MEDIUM] Chart tanpa pertanyaan + empty state lemah (R-27, C-3) — Analisis "Pengeluaran Hari Ini Rp 0" tetap render 7 bar nol + "Saku Insight" generik ("Kamu menghabiskan..."). State nol harus kalimat aksi ("Belum ada pengeluaran 7 hari terakhir"), bukan chart kosong.
6. [MEDIUM] Kontras meragukan (R-25) — chip tanggal putih di atas abu terang (Detail Saku: "Makan siang bareng tim"), teks hijau `#31c98f` di atas `#004f34`, label abu di atas krem. Ukur ulang WCAG AA 4.5:1 sebelum ship.
7. [MEDIUM] Duplikasi kontrol tema (C-3) — Profil: baris "Tema > Sistem" + segmented Sistem/Terang/Gelap di bawahnya. Satu kontrol saja.
8. [LOW] Copy tidak konsisten (R-31) — "Mkn & Mnm" (chip Analisis) vs "Makan & Minum" (Detail), "19 Agu 2026" tanpa spasi, "Saku Saya" vs "Detail Saku" vs "Saku Insight" tiga istilah untuk konsep sama.
9. [LOW] Ikon generik tanpa alasan tertulis (R-04) — set MaterialCommunityIcons dipakai sebagai default library; tombol "Alokasi" pakai glyph ▶︎; relevance tidak ditulis di mana pun.
10. [LOW] Gap vs mobileui checklist — nav floating pill sudah benar; yang belum: button tanpa state loading-morph, error form belum shake+refocus, transisi layar fade default (mobileui minta vertical slide/blur 250-350ms + staggered entry).

## Yang lolos
- R-03 overflow: tidak ada horizontal leak terlihat; grid collapses ke 1 kolom.
- R-02: tidak ada em dash di copy UI (yang ada hanya di komentar kode).
- R-17/R-18/R-36: angka dari data nyata, tanpa testimoni/klaim palsu.
- R-24: semua tab ada tujuan nyata. R-10/R-12/R-13: glass/glow/shadow dalam batas dosis.
